Monthly Attendance PDF / Print Update

Updated the Print Monthly / Save as PDF attendance layout so the TOTAL area has three columns:

T - total tardiness
X - total absences
P - total present / pumasok in the month

Notes:
- Tardy is also included in P because the pupil still entered/attended class.
- The print layout width was adjusted so T, X, and P fit properly under TOTAL.
- Use Print Monthly, then choose Save as PDF in the browser print dialog.
